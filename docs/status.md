# Статус текущего v1

## Уже реализовано

- Expo/React Native каркас на TypeScript.
- Первый запуск с выбором типа аккаунта.
- Поток `сборщик данных -> QR / тестовый режим`.
- Главное меню и настройки.
- Список сортов и карточка сорта.
- Общий сценарий для ходов `1,2,3,6,7,8,9` на 3 делянки.
- Локальное хранилище состояния.
- Mock-sync очередь.
- Заглушки для ролей `аналитик` и `руководитель`.
- Базовый тестовый слой и документация.

## Пока не реализовано

- Реальная интеграция с Google Sheets.
- Реальные изображения-примеры заражения и повреждений.
- Остальные шаги карточки сорта вне `1,2,3,6,7,8,9`.
- Реальная бизнес-логика для ролей `аналитик` и `руководитель`.
- Тяжелые e2e-сценарии уровня Detox/Maestro.

## Причина неполноты

Оставшиеся шаги карточки сорта и часть экранов не реализованы по продуктовой причине: по ним пока нет утвержденного описания и правил поведения.
