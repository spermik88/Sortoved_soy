# Ручной тестовый чеклист

## Первый запуск

- Открывается экран выбора типа аккаунта.
- Доступны роли `Сборщик данных`, `Аналитик данных`, `Руководитель`.

## QR happy path

- При выборе `Сборщик данных` открывается экран сканирования QR.
- После сканирования валидной `http/https` ссылки открывается экран подтверждения сорта.
- После подтверждения пользователь попадает в главное меню.

## Duplicate QR

- Повторное сканирование уже добавленной ссылки не создает дубликат.
- Показывается сообщение `Сорт уже добавлен`.

## Test mode

- Кнопка `Пропустить шаг` переводит в предупреждение о тестовом режиме.
- После подтверждения доступно главное меню в тестовом режиме.
- В списке сортов есть рабочий тестовый сорт.

## Ход без заражений

- Для любого активного хода `1,2,3,6,7,8,9` можно сфотографировать делянку и перейти дальше.
- На шаге заражений без карточек кнопка `Далее` доступна.
- На шаге подтверждения пакет успешно завершается.

## Ход с заражениями

- Добавляется карточка заражения.
- Пока карточка не заполнена полностью, `Далее` недоступна.
- После добавления фото, номера растения и номера ряда `Далее` становится доступна.
- Карточку можно удалить.

## Возврат в ход

- Повторный вход в частично завершенный ход возвращает на следующую незавершенную делянку этого хода.
- Прогресс одного хода не влияет на делянки других ходов.

## Карточка сорта

- На карточке сорта активны только ходы `1,2,3,6,7,8,9`.
- Остальные пункты отображаются как будущие шаги.
- Верхняя сводка меняется между состояниями `не начато`, `в работе`, `завершено` по всем активным ходам.

## Очередь и offline

- При наличии сети пакет подтверждается и помечается как синхронизированный.
- При отсутствии сети пакет остается в очереди.
- После возврата сети очередь повторно обрабатывается.

## Перезапуск приложения

- Сохраняются выбранная роль и режим.
- Сохраняются список сортов и черновики активных ходов.
- Сохраняются completed-статусы уже пройденных делянок.

## Смена роли

- В настройках можно сменить тип аккаунта.
- Перед переключением показывается предупреждение об очистке локальных данных сборщика.
- После смены роли старое состояние сборщика не остается в UI.
