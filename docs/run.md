# Запуск проекта

## Требования

- `Node.js 22+`
- `npm 11+`
- Expo Go на устройстве или Android Emulator

## Установка

```bash
npm install
```

## Основные команды

Запуск dev server:

```bash
npm start
```

Запуск Android:

```bash
npm run android
```

Запуск iOS:

```bash
npm run ios
```

Запуск web:

```bash
npm run web
```

Запуск тестов:

```bash
npm test
```

## Рекомендуемый режим проверки

Для текущего этапа основной путь проверки — `Expo Go demo`.

Что проверять через Expo Go:

- выбор роли;
- QR-поток;
- тестовый режим;
- карточку сорта;
- сценарии ходов `1,2,3,6,7,8,9`;
- локальное сохранение состояния между перезапусками.
